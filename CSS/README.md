****CSS Specificity****
 - 
 - tag **!important** -> This will bypass any other CSS and reflect this CSS. 

       - tag -> 1
       - .class -> 10
       - #id -> 100
       - tag.class -> 11
       - tag#id -> 101
       - tag > #id -> 101
       - tag #id .class -> 111

- input tag -> Varies when you specify type of input
    
       - input -> 1
       - input[type = text] -> 11
